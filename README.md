# Лабораторные работы по ООП

Проекты на C++20:

- `lab_1` — работа со строками и динамической памятью
- `lab_2` — класс многочлена: сложение, умножение и вычисление значения

Каждая лабораторная собирается отдельно с помощью CMake (версия 3.16 или новее). Тесты используют GoogleTest; при необходимости CMake загрузит его при настройке проекта

```bash
cmake -S lab_1 -B lab_1/build
cmake --build lab_1/build
ctest --test-dir lab_1/build --output-on-failure
```

Для второй лабораторной замените `lab_1` на `lab_2`.
